# Restaurant Ordering System
Object-oriented Python restaurant ordering system with menu management, order processing, invoices, discounts, and multiple payment methods.

## Overview

The program simulates a restaurant ordering process. A customer can enter their details, view the menu, search for food or drinks, add items and quantities to an order, receive an invoice, and complete the payment.

The system also keeps track of customers and orders and generates unique order, invoice, and payment IDs.

## Features

- Load food and drink items from a text file
- Display vegetarian, non-vegetarian and drink menu sections
- Search for menu items by full or partial name
- Add multiple items and quantities to an order
- Calculate the order subtotal
- Apply a 10% discount to orders of €20 or more
- Calculate 9% tax
- Generate an invoice
- Support cash, card and online payments
- Generate payment receipts
- Track customers and their orders
